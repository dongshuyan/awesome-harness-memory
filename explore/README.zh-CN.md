# 记忆地图

这是较早的双语概念地图，保留 32 项资源用于解释关系。最新完整目录请进入 [在线知识导航](https://dongshuyan.github.io/awesome-harness-memory/)；本地图也可 [在线打开](https://dongshuyan.github.io/awesome-harness-memory/explore/index.zh-CN.html)。

[English](README.md) · [简体中文](README.zh-CN.md)

用交互地图理解 Agent 系统中的记忆。选择一个视角、点击概念，即可查看解释、区别、关系依据和代表资源。中文版与英文版使用相同的概念、连线和来源；系统、论文和作品名称保留原名，方便检索。

## 打开地图

在仓库根目录运行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

打开[中文版](http://127.0.0.1:8000/explore/index.zh-CN.html)或[英文版](http://127.0.0.1:8000/explore/)。页面右上角可以切换语言，当前视角和概念会随之保留。此原型尚未部署到线上。

## 怎么看

- **连续性**：交互之间，哪些信息会延续？
- **记忆构建**：信息如何成为可用的记忆？
- **变化与控制**：事实、会话或访问条件变化时，会发生什么？

三个视角共享八个概念。切换视角时，当前概念会保留，即使它不在新视角的重点范围内。实线表示文档中的系统实例，虚线表示编者归纳的关联；点击详情中的“为什么有关联”可查看解释与来源。文学作品单独标为类比。

地图关联了 19 项技术资源和 6 项文学作品，资源库保留全部 32 项条目。另有 7 项资源尚未映射到概念，但仍可从资源库打开。论文与评测中重复出现的条目合并展示，并保留两个入口。这些视角和关联仍可随调研调整。

使用 Tab 在控件之间移动，方向键切换视角，Enter 选择概念，Esc 关闭资源详情。浏览器前进、后退会恢复对应的视角与概念。窄屏上以列表呈现概念，并保留文字关联。
