## 完成讲解不等于完成实验

六问是解释系统设计的学习清单。它综合多个来源，但没有被证明是唯一最小、数学正交或穷尽一切 Memory 机制的集合，也未通过初学者学习效果实验验证。

本仓库没有独立复现所引用论文的效果分数，也没有运行全部上游产品。作者的实验结论受数据、底座模型、预算、版本与对照条件约束。Benchmark的任务结果不能单独证明系统的权限、物理删除或内部架构。

[`memory_lab.py`](../examples/memory_lab.py)是可运行教学示例：用SQLite展示重新连接后的保存、更正、范围过滤、过期和召回。它不调用LLM；scope不构成身份认证；forget停止召回但保留历史；字符预算不是token预算。测试验证这些明确行为，不是上游产品认证或新Benchmark。

构建、数据契约、JavaScript语法和页面交互检查用于验证本站交付。独立内容审阅帮助发现问题，不能代替原始证据或实际实验。后续维护围绕来源变化和新出现的学习需求开展，见[维护计划](../ROADMAP.md)。
